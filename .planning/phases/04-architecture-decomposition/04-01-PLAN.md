```typescript
import { WidgetStatus, ResultWarning } from '../types';

export const loadingStatus: WidgetStatus = { state: 'loading' };
export const loadedStatus: WidgetStatus = { state: 'loaded' };
export function errorStatus(msg: string): WidgetStatus {
  return { state: 'error', error: msg };
}
export function warnedStatus(warnings: ResultWarning[]): WidgetStatus {
  return { state: 'loaded', error: warnings.map(w => w.message).join('; ') };
}
```

**5 simple domain hooks** — Each follows the identical pattern. Per D-01, each hook owns its fetch, status, and data state. Per D-10, fetch uses `useCallback([])`. Each hook also owns its own polling interval via `useEffect`.

For each hook, the structure is:
1. `export interface XHookResult { data: <type>; status: WidgetStatus; fetch: () => Promise<void>; }` — named export, not default
2. `export function useX(): XHookResult` — named export per codebase convention
3. `useState` for data (initialized from `mockMarketData.<field>`) and status (initialized to `loadingStatus`)
4. `useCallback(async () => { ... }, [])` for fetch — unwraps DataResult, sets status, sets data
5. `useEffect` with `setInterval` for polling + initial fetch call, returns cleanup. Deps array contains only the stable `fetch` ref.
6. The safety-net `catch(e)` wrapping the DataResult check (matching existing pattern in useMarketData.ts)
