## Data Contract (Phase 3 Primary Output)

This section replaces the visual design contract for this infrastructure phase. It defines the TypeScript interface that Phase 5 and future UI phases consume.

### WsStatus Type

```typescript
// src/types/index.ts — add after WidgetLoadState
export type WsStatus = 'connected' | 'connecting' | 'reconnecting' | 'failed';
```

Source: CONTEXT.md D-07, RESEARCH.md Standard Stack supporting table.

### State Transition Contract

| From | To | Trigger |
|------|----|---------|
| (initial) | 'connecting' | `wsManager.connect()` called |
| 'connecting' | 'connected' | WebSocket `onopen` fires |
| 'connected' | 'reconnecting' | WebSocket `onclose` fires or silent drop detected |
| 'reconnecting' | 'connected' | WebSocket `onopen` fires (any attempt < 10) |
| 'reconnecting' | 'failed' | attempt count reaches 10 |
| 'failed' | 'connecting' | `wsManager.reconnect()` called manually |

Source: CONTEXT.md D-08.

### Hook Integration Contract

The `useMarketData` hook exposes `wsStatus: WsStatus` in its return value. No React context is added — the callback pattern keeps `WebSocketManager` framework-agnostic.

```typescript
// useMarketData return shape (addition only)
wsStatus: WsStatus   // was: wsConnected: boolean
```

Phase 5 reads `wsStatus` from the hook to drive UI-03 (ribbon status indicator) and the reconnect button wired to `wsManager.reconnect()`.

Source: CONTEXT.md D-07, RESEARCH.md Pattern 5.

### Public API Surface

| Method | Signature | Consumer |
|--------|-----------|----------|
| `connect()` | `() => void` | `useMarketData` useEffect |
| `subscribe()` | `(cb: WsCallback) => () => void` | `useMarketData` useEffect |
| `onStatusChange()` | `(cb: (status: WsStatus) => void) => () => void` | `useMarketData` useEffect |
| `getPrice()` | `(symbol: string) => number \| undefined` | `twelveDataService.ts` wsToItem, buildRibbonFromWs |
| `getPrevPrice()` | `(symbol: string) => number \| undefined` | `twelveDataService.ts` wsToItem, buildRibbonFromWs |
| `reconnect()` | `() => void` | Phase 5 UI reconnect button |
| `disconnect()` | `() => void` | `useMarketData` useEffect cleanup |

Source: CONTEXT.md D-09, D-10; RESEARCH.md Pattern 1.
